# API Usage

**What it is.** How much each API key is being used.

**Why it helps.** It shows whether a key is working, which system is busiest, and whether anything is being used more than you expected.

Click **Admin**, then **API Usage**.

![API Usage](../img/shots/admin/api-usage-full.png)

Shows how much each key is being used, and what it asked for.

Use it to check a key is working, to see which system is busiest, and to spot a key being used
more than you expected.
