# Dashboards

A dashboard puts several charts and numbers on one screen.

Click **Dashboards**.

![The Dashboards list](../img/shots/analytics/dashboards-list.png)

Click one to open it.

![A dashboard](../img/shots/analytics/dashboard-viewer-full.png)

## Filtering a dashboard

A dashboard can have filters at the top. Choose a value and every chart updates together.

Click **Clear all** to go back to the full picture.

## Refreshing

Click **Refresh**. Dashboards remember their last result for speed, so use this when you need
the very latest numbers.
